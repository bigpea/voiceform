VoiceForm

Compila moduli PDF della PA italiana parlando. Nessuna tastiera, nessun mouse.

Roberto Sgobio  ·  Sara Lanzafame
01

Il problema

67M
persone al mondo soffrono di disturbi legati al tremore — non riescono a compilare autonomamente form digitali o PDF.

Per chi ha tremore essenziale o emiplegia, interagire con tastiera e mouse su un modulo della Pubblica Amministrazione è spesso impossibile. Il risultato: dipendenza da terze persone per operazioni quotidiane come un'autocertificazione.

  • Moduli PA con decine di campi da compilare con precisione
  • Nessuna alternativa vocale nativa nei portali istituzionali
  • La persona deve delegare ad altri anche operazioni semplici
02

L'utente dice "Mi chiamo Mario Rossi, nato a Roma il 3 marzo 1970" e in meno di 2 secondi 4 campi vengono compilati automaticamente.

04

Come lo realizziamo

🎙️

Web Speech API

Trascrizione vocale browser nativa, italiano, zero costo, zero API key

🔍

Pattern Matching

Regex + confidence score server-side per mappare il parlato ai campi del PDF

📄

pdf-lib

Lettura campi AcroForm + compilazione PDF server-side, download immediato

MVP1 — Zero API key esterne.  |  MVP2 — Integrazione opzionale con API Anthropic / OpenAI per migliorare comprensione linguaggio naturale e gestire moduli complessi.
